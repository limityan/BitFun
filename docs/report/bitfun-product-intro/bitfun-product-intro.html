openbitfun.com

BitFun

一个把 Code Agent、办公协作、桌面操控与个人助理装进同一桌面端的 ADE。

产品定位

下载即用的桌面 Agent 套件，也是可扩展、可审计、可长期运行的 Agent 基座。直接使用官方 Agent，也可以用 Markdown、MCP、Skill、Mini App 或源码 fork 定义领域 Agent。

GitHub: GCWing/BitFun Windows · macOS · Linux

愿景

从会聊天的 AI 工具，走向可验证、可协作、可自我迭代的智能工作系统。

01

Agentic Coding

AI 不再只补全代码，而是读仓库、改文件、跑验证、解释结果。

02

Context Engineering

会话、记忆、项目上下文、工具权限和规范一起进入执行环境。

03

Quality Gates

Plan、Debug、Review、Deep Review 把完成感绑定到证据和审查。

Code Agent

Agentic、Plan、Debug、Review 四种模式，覆盖开发、排障与检视。

Cowork

文档、表格、幻灯片与知识整理能力，适合办公和项目协作。

Computer Use

看屏幕、动鼠标键盘，把浏览器和桌面应用交给 Agent 操作。

Agent 生态

MCP、Skill、Mini App、生成式 UI、远程控制与长期记忆内置。

给用户带来的价值

Less switching. More agency.
效率

编码、办公、桌面执行与远程指挥收进一个工作台。

协议栈、文件、终端、Git 与远程能力默认就绪。
掌控

数据留在本机，会话、记忆和工作目录可迁移、可审计。

适合长期运行、隐私与合规场景。
演进

从 Markdown Agent 到整仓 fork，让 BitFun 改进 BitFun。

沉淀成可复用 Agent、工具和 Mini App。
